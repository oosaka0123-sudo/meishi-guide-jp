# meishi-guide-jp

名刺を初めて作る人でも、作り方・サイズ・用紙・デザイン・印刷会社選び・発注まで迷わない、日本一わかりやすい名刺ガイドを目指すサイトです。

## 方針

- 初心者最優先。専門用語は図解前提で説明する
- 「名刺の作り方」を中心に、関連テーマをクラスター化する
- 目的別導線（早く作りたい / 安く作りたい / おしゃれに作りたい）を用意する
- 印刷会社比較は比較基準と検証方法を公開する
- 実物写真・発注体験・失敗例など一次情報を重視する
- 日本語SEO、モバイルファースト、静的配信を基本とする

## 初期コンテンツ

1. トップページ
2. 名刺の作り方 完全ガイド
3. 名刺サイズ・規格
4. 用紙・厚さ・質感
5. 名刺デザインの基本
6. 名刺印刷会社比較
7. 名刺の料金相場
8. 用途別ガイド
9. よくある失敗と対策
10. FAQ
11. 運営者情報 / 比較ポリシー / プライバシーポリシー / お問い合わせ

## 技術方針

第一候補は Astro + TypeScript。コンテンツ中心のサイトとして、表示速度・SEO・保守性を優先します。料金や比較データは将来JSON/CMSへ分離し、最終更新日を明示できる構造にします。

詳細は `docs/SITE_PLAN.md` を参照してください。
