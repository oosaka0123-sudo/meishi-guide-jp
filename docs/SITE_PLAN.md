# サイト設計 v0.1

## 目的

「名刺を作りたい」と思った初心者が、検索から来て、そのまま迷わず完成・発注まで進めるサイトにする。

## 3者クロスチェック反映

### 共通結論
- ページを横並びにしない。「名刺の作り方」を中心に情報を階層化する。
- 初心者が詰まりやすい専門用語は、文章だけでなく図解・比較表で説明する。
- 実物写真、発注体験、失敗例など一次情報を増やす。
- 印刷会社比較は、広告都合ではなく比較基準・更新日・検証方法を公開する。
- 最初から全コンテンツを作り込まず、検索意図が強いページから公開する。

## トップページ導線

最初の選択肢を3つに絞る。

1. 早く名刺を作りたい
2. 安く名刺を作りたい
3. おしゃれな名刺を作りたい

その下に「初めてなので最初から知りたい」導線を置き、完全ガイドへつなぐ。

## 情報構造

- `/` トップ
- `/how-to/` 名刺の作り方 完全ガイド
  - `/how-to/self/` 自作する
  - `/how-to/print-service/` 印刷会社へ発注する
  - `/how-to/designer/` デザイナーへ依頼する
- `/size/` サイズ・規格
- `/paper/` 用紙・厚さ・質感
- `/design/` デザインの基本
- `/printing/` 印刷・入稿の基礎
- `/compare/` 印刷会社比較
- `/price/` 料金相場
- `/use-case/` 用途別
  - フリーランス
  - 副業
  - 就活
  - 店舗
  - 営業
- `/mistakes/` よくある失敗
- `/faq/` FAQ
- `/glossary/` 用語解説
- `/about/` 運営者情報
- `/comparison-policy/` 比較ポリシー
- `/privacy/` プライバシーポリシー
- `/contact/` お問い合わせ

## MVP

初回公開は以下を優先する。

1. トップ
2. 名刺の作り方 完全ガイド
3. サイズ・規格
4. よくある失敗
5. FAQ
6. 運営者情報 / 比較ポリシー / プライバシー

印刷会社比較は重要だが、一次情報と比較基準が揃う前に薄い記事を公開しない。

## 技術方針

- Astro + TypeScript
- 静的生成を基本
- Markdown/MDXで記事管理
- モバイルファースト
- 画像最適化
- Sitemap / robots.txt / canonical
- Article / BreadcrumbList 等の構造化データ
- FAQ構造化データは検索エンジンの現行仕様を確認して適用
- Core Web Vitalsを優先

## コンテンツ品質ルール

- 結論を先に書く
- 専門用語を初出で説明する
- 1ページ1検索意図を基本にする
- 比較記事はデメリットも明記する
- 料金・仕様・納期には確認日を付ける
- 他サイトの要約だけで記事を作らない
- 実物写真・検証・一次ソースを優先する
